# shundabao.github.io

Personal academic homepage for Shunfeng Zheng.

## Files

- `index.html`
- `css/style.css`
- `js/main.js`
- `assets/prs-shooting.mp4`

## Add your PRS video

Put your own MP4 file at:

```text
assets/prs-shooting.mp4
```

Recommended:

- 5–8 seconds
- 16:9
- muted
- 720p is enough
- keep the file reasonably small for fast loading

The video appears when the mouse hovers over:

`PRS Pro Shooter · Australia`

On mobile, the hover preview is disabled and the link opens the Impact Scoring shooter profile normally.

## Preview locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
